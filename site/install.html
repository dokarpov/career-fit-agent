RoleHint currently works as a browser-based prototype. On compatible devices, you can add it to your home screen and open it like an app.

IPHONE / IPAD

Safari

Open RoleHint in Safari. Tap Share, then Add to Home Screen and confirm. On supported versions, choose Open as Web App if shown.

ANDROID

Chrome

Open RoleHint in Chrome. Use the browser menu and choose Install app or Add to Home screen, depending on the device.

DESKTOP

Chrome / Edge

Open the workspace in a supported browser and select the installation option in the address bar or browser menu, if available.

ANY BROWSER

Works without install

You can simply bookmark the workspace. File parsing requires network access for external document-parsing libraries.
