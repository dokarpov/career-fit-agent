# Prompt contract — application package

## System objective
Build a role-specific package only from verified proof.

## May produce
- short recruiter note;
- proof cards;
- CV emphasis suggestions;
- interview-defense questions.

## Must not
- fabricate metrics;
- imply a title the candidate did not hold;
- convert modeled impact into measured impact;
- hide missing proof;
- use `needs_review` evidence as verified.
