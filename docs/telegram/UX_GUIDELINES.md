# Telegram Mini App UX v1.1

Applied:
- mobile-first;
- Telegram dynamic theme variables;
- safe-area/content-safe-area;
- native MainButton for the single current primary action;
- native BackButton for secondary screens;
- haptics on key transitions;
- no duplicate top navigation;
- simple section/list structure instead of desktop drawers;
- accessible labels;
- lightweight rendering;
- `initData` must be validated server-side.

Daily path: open bot → tap one action → native bottom action.
