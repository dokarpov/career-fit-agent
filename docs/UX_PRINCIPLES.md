# UX principles — current

The recurring job is:

> **Show me what is worth applying to now, and why.**

The user should not repeatedly search boards, copy job descriptions, build queries, deduplicate listings, or manufacture proof objects for the system.

The default interaction sequence is:

`Telegram batch → original vacancy / match → evidence-backed pack → final human approval/send`

Principles:
- attention before navigation;
- original source before derivative snippet;
- hard eligibility before evidence fit;
- evidence gaps affect effort/priority unless truly disqualifying;
- one primary next action;
- evidence stays background infrastructure until a meaningful conflict/gap appears;
- permission and outward representation remain human-controlled.
